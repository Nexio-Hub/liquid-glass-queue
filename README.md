# Liquid Glass Queue

Make a template website. The theme is like Apple's Liquid Glass, there is a text like a title saying "Title1", another text smaller under saying "Subtext1". Make like a box with rounded corners and inside it a textbox with the text "Textbox1" and a blue button under with "Button1". After the user writes something there and clicks the button there is a new pop up saying "Putting you in the queue..." and then after like 5 seconds another pop up saying "You've been succesfully put in the queue!" with a clock in the left of the text and a blue "OK" button that closes the pop up. Keep the theme like Apple's Liquid Glass
